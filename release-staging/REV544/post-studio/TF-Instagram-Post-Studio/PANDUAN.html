Panduan Post Studio

1. Pasang plugin baru

Ekstrak ZIP. Buka chrome://extensions, aktifkan Developer mode, pilih Load unpacked, lalu pilih folder TF-Instagram-Post-Studio yang berisi manifest.json. Plugin ini terpisah dari TF Multi-Analyst Scanner.

Klik ikon TF Instagram Post Studio untuk membuka sidebar. Tombol Buka Studio penuh memberi ruang lebih luas. Jalankan satu Studio pada satu waktu.

2. Login dan siapkan daftar

Login di account.tradersfamily.id dengan akun Anda. Impor file .xlsx hasil multi-link scan. Sheet Hasil Scan dibaca, lalu Centang diurutkan: Priority, Prospect, Basic. Urutan semula dipertahankan dalam kategori yang sama. Sheet Skip tidak ikut diproses.

Jumlah default adalah 15 analis baru. Anda juga bisa menempelkan link custom, satu link per baris, memilih pair, lalu klik Tambahkan link. Centang link yang akan digunakan. Pair tiap baris bisa diubah. Link + pair yang sama dalam antrean dilewati.

Antrean awal kosong. Tarik satu file .xlsx ke sidebar, atau klik Import Excel untuk memilih file. Tombol × pada setiap baris menghapus link dari antrean. Menghapus link tidak menghapus folder hasil. Antrean yang Anda susun akan dipulihkan saat Studio dibuka kembali.

3. Pilih lokasi dan mulai

Klik Pilih folder penyimpanan, lalu pilih lokasi induk. Izinkan penyimpanan saat Chrome meminta. Plugin membuat folder Post Instagram Analis Performers di dalamnya. Anda juga boleh memilih folder itu langsung jika sudah ada.

Klik Start. Satu tab kerja aktif digunakan bergantian untuk semua analis agar grafik situs selesai dirender. Biarkan tab analis tetap aktif selama pengambilan; kontrol proses tetap tersedia di sidebar. Pause menjeda proses; tekan Lanjut untuk meneruskan. Stop menghentikan setelah operasi yang sedang berjalan selesai. Timer tidak menghitung waktu selama Pause.

Biarkan halaman Studio / sidebar tetap terbuka selama proses. Jika ditutup atau Chrome terhenti, buka Studio kembali dan klik Start; hasil yang lengkap dapat dilewati, sedangkan folder yang belum selesai diproses ulang.

4. Isi setiap carousel

  1. Profil analis, Price, Profit USD, Pips, Months Since, grafik Growth asli dari DOM, dan Signal Frequency. Filter ALL dan pair diterapkan lebih dahulu.
  2. Summary lengkap setelah See More, termasuk detail tambahan, serta Informasi Aktivitas Channel dari Statistics.
  3. Profit Per Month untuk setiap tahun, terbaru dahulu. Semua tombol tahun dibaca. Satu tahun hingga 12 bulan per slide; data lebih panjang dibagi ke slide berikutnya.
  4. Overview Score beserta komponen dan History Score. Riwayat lebih dari 8 entri dibagi menjadi slide lanjutan.

Data disusun ulang untuk desain ungu gelap 1080 × 1350. Grafik Growth memakai gambar kartu DOM asli. Angka diambil dari halaman, tidak dihitung ulang oleh Post Studio. Bagian Score / Informasi Aktivitas mengikuti cakupan yang disediakan situs dan dapat memakai periode penilaian tersendiri.

Nama file dan jumlah slide mengikuti data aktual. Deskripsi .txt memuat metadata Excel, Survived Month dari filter scan jika tersedia, ringkasan terbaru, tautan sumber, serta hashtag Anda. Kolom yang tidak tersedia ditulis sebagai tidak tersedia.

Plugin mengecek link + pair pada manifest dan memastikan semua file masih ada serta berisi data. Hanya hasil lengkap yang dilewati. Folder parsial dipakai kembali. Nomor folder melanjutkan nomor terbesar yang sudah ada. Hapus centang opsi lewati jika ingin membuat ulang hasil lengkap; hasil baru disimpan di folder bernomor berikutnya.

Jika proses gagal

Pesan gagal tercantum pada baris link. Login yang berakhir, pair yang tidak tersedia, halaman yang belum selesai dimuat, atau statistik situs yang tidak tersedia tidak dijadikan data kosong. Perbaiki penyebabnya, pilih baris itu, lalu Start kembali.

Semua file Excel dan hasil disimpan secara lokal. Plugin hanya memiliki akses situs TradersFamily yang diperlukan; tidak mengunggah atau memublikasikan post ke Instagram secara otomatis.
